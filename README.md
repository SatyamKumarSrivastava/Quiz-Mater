**Quiz Master**

Quiz Master is an interactive web-based quiz application developed using HTML, CSS, and JavaScript. It allows users to test their knowledge across different subjects and difficulty levels.

The application provides multiple-choice questions, calculates the user's score, displays explanations, and allows users to generate a Certificate of Completion in PDF format.

**Features**
User name login
Multiple quiz categories
Three difficulty levels:
Beginner
Intermediate
Advanced
Multiple-choice questions
Automatic score calculation
Explanations for questions after quiz completion
Certificate of Completion
PDF certificate generation
Restart Quiz option
Logout option for another user
Responsive design
Attractive animated user interface
Can be deployed using GitHub Pages
Quiz Categories

The project currently contains four categories:

Category	Levels
History:	Beginner, Intermediate, Advanced
Science:	Beginner, Intermediate, Advanced
Literature: Beginner, Intermediate, Advanced
Mathematics:	Beginner, Intermediate, Advanced

Each category contains 5 questions at each difficulty level, giving the application a total of 60 questions.

**How to Use**
Open the Quiz Master application.
Enter your name.
Click Login.
Select a Field.
Select a Difficulty Level.
Click Start Quiz.
Answer the multiple-choice questions.
Complete the quiz to view your score.
Read the explanations provided for the questions.
Click Generate Certificate to create your certificate.
Click Restart Quiz to play another quiz.
Click Logout to allow another person to use the application.
Certificate

After completing a quiz, users can generate a personalized certificate containing:

User's name
Quiz category
Difficulty level
Score
Completion information
Date of completion

The certificate can also be downloaded as a PDF.
